# Platform matrix

The distinction this file exists for: **verified** means someone ran it on a machine and watched
it work. **Documented** means the vendor's documentation says so and nobody here has run it yet.
The README never promises anything from the second column.

Last updated 2026-10-31.

## How to update this file

Run the thing, then edit the row. A row moved from documented to verified in the same commit as
a `staff build` change is the normal shape of a pull request here.
