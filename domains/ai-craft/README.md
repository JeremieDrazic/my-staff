# ai-craft

Building the tooling itself: writing a skill, a role or an eval, auditing one, and making it work on every platform.

Status: `draft` · version 0.1.0 · family Meta

> Generated by `staff readme` from `domain.json` and this directory. Edit those, not this file.

## Install

```bash
npx skills add jeremiedrazic/my-staff --skill <skill-name>   # ~70 agents
claude plugin marketplace add jeremiedrazic/my-staff && claude plugin install ai-craft@my-staff
```

## Skills

| Skill | When to use it |
| :- | :- |
| [`write-a-skill`](skills/write-a-skill/SKILL.md) | Write a new agent skill, or rewrite one that never triggers. Use when the user wants to turn a repeated piece of work into something an agent can load on its own — a review pass, a build procedure, a study method — or when an existing skill is ignored, loads too much, or only works on one platform. Not for writing a role that gets delegated a task; that is write-an-agent. |
